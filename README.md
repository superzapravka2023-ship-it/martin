# DCA-скальпер для Bybit

Скальпер с усреднениями на 5-минутном таймфрейме. Лонг и шорт, до 4 доборов,
выход только по тейк-профиту от средней цены. Стоп-лоссов по сделкам нет.

## Как работает

1. Раз в минуту сканирует вселенную Bybit USDT-перпов (листинг ≥ 30 дней,
   оборот ≥ $10M, топ-120 по обороту).
2. Сигнал: цена выше EMA(50) и RSI(7) вышел вверх из зоны ниже 30 → лонг.
   Цена ниже EMA(50) и RSI(7) вышел вниз из зоны выше 70 → шорт.
   Дополнительно: ATR(14) ≥ 0.4% от цены, движение за час < 8%,
   при падении BTC более 3% за час лонги блокируются.
3. Вход маркет-ордером на $200 номинала. **Сразу следом выставляется вся сетка
   лимиток на добор** — четыре ордера на −0.8 / −1.8 / −3.2 / −5.0% от входа
   (для шорта зеркально).
4. Тейк-профит — лимитный reduceOnly на 0.6% от средней цены, на весь объём.
   После каждого сработавшего добора старый тейк снимается и выставляется новый
   от новой средней.
5. **Если позиция закрылась по тейку без доборов, все неисполненные лимитки
   сетки снимаются.** Это делает `reconcile()` на каждом цикле: увидев символ
   с ордерами, но без позиции, он вызывает `cancel_all`.
6. Кулдаун 60 минут на монету после закрытия.

## Арифметика сетки

| Ордер | Отклонение | Номинал | Накоплено | Средняя ниже входа |
|---|---|---|---|---|
| Вход | 0% | $200 | $200 | 0% |
| Добор 1 | 0.8% | $260 | $460 | 0.45% |
| Добор 2 | 1.8% | $340 | $800 | 1.03% |
| Добор 3 | 3.2% | $440 | $1240 | 1.81% |
| Добор 4 | 5.0% | $580 | $1820 | 2.85% |

Полная сетка: средняя на 2.85% ниже входа, от дна нужен отскок 2.88%.
Три полные сетки — $5460 номинала, эффективное плечо 5.46x на депозит $1000.
Начальная маржа при 20x: $273 (при 10x было бы $546 — поэтому 20x, запас свободных
средств больше при том же риске, потому что номинал одинаковый).

Убыток по трём полным сеткам при дальнейшем падении: −10% → $402, −15% → $683,
−20% → $964. То есть депозит $1000 кончается примерно на −20% от первых входов.

Чистый профит после комиссий: $1.05 без доборов, $2.41 / $4.20 / $6.51 / $9.55
с одним–четырьмя. (Цифры проверены расчётом, см. «Проверка».)

## Защита

Стопов по сделкам нет — как и задумано. Единственный предохранитель:
при падении эквити ниже `EQUITY_FLOOR` ($600) бот перестаёт открывать новое
и пишет в Telegram. Открытые позиции продолжает вести.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env    # заполнить ключи
python main.py
```

### Настройка Bybit

1. Демо-аккаунт, API-ключ с правами на торговлю деривативами.
2. В интерфейсе биржи включить **кросс-маржу** для Unified-аккаунта —
   это настройка уровня счёта, бот её не меняет.
3. Режим позиций — **One-Way** (бот использует `positionIdx=0`).
   Hedge-режим не поддерживается.
4. Плечо бот выставляет сам (20x) при первом входе по каждому символу.

### Railway

- Деплой из GitHub, тип сервиса — worker (`Procfile` уже есть).
- Переменные окружения — из `.env.example`.
- Подключить volume и выставить `DB_PATH=/data/bot.db`, иначе при каждом
  редеплое теряются журнал сделок и кулдауны.

## Управление из Telegram

Меню на инлайн-кнопках, команды `/menu` `/stats` `/positions` `/help`.
Отвечает только тому чату, чей id в `TELEGRAM_CHAT_ID`.

- **Главное меню** — состояние, эквити, плавающий PnL, занятые слоты, итог за сутки.
- **📊 Статистика** — сутки / 7 дней / 30 дней: сделки, винрейт, PnL, средняя глубина сетки.
- **📂 Позиции** — каждая позиция: средняя, номинал, доборы `▰▰▱▱`, возраст, PnL.
  Под каждой — кнопка закрытия.
- **❌ Закрыть** — с подтверждением: снимает остаток сетки и закрывает по рынку.
  Это ручной способ освободить слот, занятый зависшей позицией (стопов-то нет).
- **⏸ Пауза** — перестать открывать новое. Открытые позиции продолжают вестись:
  доборы исполняются, тейк переставляется.
- **⚙️ Параметры** — что сейчас в конфиге. Только просмотр: меняется
  переменными окружения в Railway.

Интерфейс живёт в отдельном потоке и делит с главным циклом общий замок,
поэтому ручное закрытие не может пересечься с `reconcile`.

## Настройка частоты сделок

`RSI_OVERSOLD=35` / `RSI_OVERBOUGHT=65` — заметно больше сделок.
`25` / `75` — меньше и отборнее. `MIN_ATR_PCT=0.5` — отсечь вялые монеты.

**Не ставь `RSI_PERIOD=14` с порогами 30/70** — на 5m в связке с фильтром EMA(50)
эта комбинация не даёт сигналов вообще (проверено: 0 за 100 монето-дней).
Если хочется именно RSI(14), пороги должны быть 40/60.

## Проверка

Что протестировано на моке биржи и на модельных данных:

- RSI совпадает с эталонными значениями Уайлдера до второго знака; ATR на
  постоянном диапазоне даёт точное значение; EMA возвращает `None` при нехватке баров.
- Выход по тейку **без доборов** → сетка снимается одним `cancel_all`, пишется
  кулдаун, сделка уходит из активных.
- Доборы по одному → тейк каждый раз снимается и переставляется от новой средней.
- Полная сетка → средняя 97.1494 при входе 100, тейк 97.7323, PnL +10.92.
- Шорт зеркален: доборы выше входа, тейк ниже, PnL симметричен.
- Вся арифметика таблицы выше пересчитана кодом, а не прикидкой.

Что **не** протестировано: живые вызовы Bybit — исходящие соединения к бирже
из среды сборки заблокированы. Первый запуск проверяй сам: подними бота на демо,
дождись первого входа и убедись, что сетка и тейк встали так, как в сообщении
Telegram.

## О чём помнить

Схема без стопов даёт винрейт 90–95% и ровную кривую до тех пор, пока три
сетки не зальются одновременно на общем проливе. Весь результат определяется
тем, успеет ли накопленная прибыль перекрыть этот день. Ежедневный отчёт
показывает нереализованный PnL по открытым позициям — смотреть надо именно на
него, а не на список закрытых сделок, который будет состоять из сплошных плюсов.
